مستندات شبکه (Network Documentation)
عنوان پروژه: معماری شبکه سازمانی با مسیریابی چند لایه

تاریخ: 2026-09-26

۱. بررسی کلی (Executive Summary)
این شبکه جهت مدیریت متمرکز ترافیک در چندین بخش مختلف طراحی شده است. سیستم مبتنی بر ساختار چند روتره است که اتصال بین سرورها (سرویس‌های مرکزی) و کلاینت‌ها (End Devices) را در زیرشبکه‌های (Subnets) مجزا فراهم می‌کند.

۲. مشخصات ساختار (Topology Overview)
هسته شبکه (Core Layer): از روترهای سری ۲۹۱۱ سیسکو برای مسیریابی بین‌شبکه‌ای (Inter-VLAN/Subnet Routing) استفاده شده است.
اتصالات (Connectivity):
لینک‌های Gigabit Ethernet برای اتصال روترها به یکدیگر (Backbone) استفاده شده تا پهنای باند کافی برای ترافیک سرورها فراهم باشد.


وئیچ‌های لایه دسترسی (Access Layer) از نوع ۲۹۶۰ هستند که وظیفه اتصال مستقیم سیستم‌های نهایی (PCها) را بر عهده دارند.
بخش‌بندی (Segmentation

شبکه به زیرشبکه‌های مجزا تقسیم شده است:



بازه 192.168.1.0/24 (بخش سمت چپ بالا)


بازه 192.168.2.0/24 (بخش سمت چپ پایین)


بازه 127.22.16.0/24(سمت راست بالا)

بازه 126.10.10.0/24 (بخش سمت راست پایین)


این تفکیک باعث می‌شود ترافیک Broadcast کنترل شده و امنیت شبکه افزایش یابد.
۳. سرویس‌های شبکه (Network Services)
تعداد زیادی سرور (Server-PT) برای ارائه سرویس‌های مختلف تعبیه شده‌اند که در نقاط مختلف شبکه توزیع شده‌اند (توزیع بار).
مسیریابی بین این زیرشبکه‌ها توسط روتر مرکزی انجام می‌شود که نشان‌دهنده یک طراحی Star/Mesh Hybrid است.
