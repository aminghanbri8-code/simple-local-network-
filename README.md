# simple-local-network-
۱. اهداف شبکه (Network Objectives):

هدف اصلی: اتصال دستگاه‌های داخلی (صندوق فروش، دستگاه قهوه‌ساز هوشمند، دوربین‌های نظارتی و سیستم مدیریت محتوا) به یکدیگر و اینترنت.
سطح دسترسی: تفکیک ترافیک شبکه (VLAN بندی برای جداسازی شبکه مهمان از شبکه کاری).
۲. مشخصات سخت‌افزاری (Hardware Inventory):

مرکز شبکه (Core/Distribution): [مثلاً: سوئیچ ۲۴ پورت Cisco Catalyst 2960]
تجهیزات انتهایی (End Devices):
تعداد سیستم‌ها: [مثلاً: ۲ عدد لپ‌تاپ مدیریتی]
تعداد دستگاه‌های IoT: [مثلاً: دوربین‌های نظارتی و سیستم موزیک‌پلیر]
Gateway: [آدرس IP مودم یا روتر اصلی]
۳. طرح آدرس‌دهی (IP Addressing Scheme):

بازه شبکه (Subnet): 192.168.1.0/24
درگاه پیش‌فرض (Default Gateway): 192.168.1.1
سرویس DHCP: فعال برای دستگاه‌های کلاینت (Range: 192.168.1.50 - 192.168.1.150)
۴. نکات امنیتی (Security Notes):

استفاده از پروتکل‌های امنیتی در وایرلس (WPA3).
مسدود کردن پورت‌های استفاده‌نشده روی سوئیچ جهت جلوگیری از نفوذ فیزیکی.
